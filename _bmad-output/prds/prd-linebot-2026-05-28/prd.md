# Linebot 重建

## 產品概述

重建舊版 LINE 回話機器人（2023/2025 版年久失修），以 TypeScript + GCP Cloud Run 為基礎，加入對話紀錄、後台管理與關鍵字規則設定，供個人與朋友群組日常使用。

**目標用戶：** 開發者本人（管理員）＋朋友群組成員（一般用戶）

---

## 功能需求

### F1 — LINE Bot 核心

**FR-1.1** Bot 接收 LINE Webhook 事件，根據訊息內容路由至對應處理器。

**FR-1.2** 收到無對應規則的訊息時，回覆預設回應（可於後台設定）。

**FR-1.3** 支援一對一訊息與群組訊息。

### F2 — 看妹子（PTT Beauty 爬蟲）

**FR-2.1** 使用者傳送關鍵字「看妹子」時，爬取 PTT Beauty 版，隨機抽取一篇含圖文章並回傳圖片連結。

**FR-2.2** 爬蟲需帶 `over18=1` cookie，跳過 PTT 年齡驗證。

**FR-2.3** 若爬取失敗（PTT 無回應、無圖片文章），回覆友善錯誤訊息，不讓 bot 靜默失敗。

**FR-2.4** 「看妹子」為內建預設功能；後台關鍵字規則可覆蓋或停用此功能。

### F3 — 對話紀錄

**FR-3.1** 每則收到的使用者訊息與 bot 回應，均寫入資料庫，包含：使用者 ID、時間戳、訊息內容、bot 回應內容、觸發的功能名稱。

**FR-3.2** 群組訊息額外記錄群組 ID。

**FR-3.3** 對話紀錄保留策略可於後台設定：管理員可設定 TTL 天數（如 90 天），或停用自動刪除。預設不自動刪除。

**FR-3.4** 對話紀錄寫入為非同步，不阻塞 bot 回應。

### F4 — 後台管理

> 後台為獨立網頁（同一 Express 服務，受登入保護），使用自製 UI。

**FR-4.1 查看對話紀錄**
- 後台顯示對話紀錄列表，支援依使用者 ID、日期篩選。
- 每筆顯示：時間、用戶 ID、訊息內容、bot 回應、觸發功能。

**FR-4.2 使用統計**
- 後台顯示各指令/功能的使用次數統計。
- 可依日期區間篩選。

**FR-4.3 手動推播**
- 後台可輸入 LINE 使用者 ID 與訊息內容，送出推播訊息。
- 支援對指定用戶推播（輸入一或多個 LINE 用戶 ID），非廣播。

**FR-4.4 關鍵字規則設定**
- 後台可新增/編輯/刪除關鍵字觸發規則：輸入關鍵字 → 選擇對應功能（如：看妹子、自訂文字回覆、推播）。
- 規則支援完全比對與包含比對兩種模式。
- 規則可啟用/停用，不需刪除。
- 初始內建功能：「看妹子」、「自訂文字回覆」；架構預留擴充點，後續新增功能時不需改動規則引擎。

**FR-4.5 紀錄保留設定**
- 後台可設定對話紀錄的保留天數（例如 30、60、90 天），或關閉自動刪除。
- 設定生效後，超過天數的舊紀錄於背景定期清除。

**FR-4.6 後台登入保護**
- 後台需登入（單一管理員帳號，帳號密碼由環境變數設定，不做多用戶管理）。

### F5 — 本地開發體驗

**FR-5.1** 本地啟動 server 後，搭配 ngrok 即可接收 LINE Webhook，不需部署。

**FR-5.2** `.env.example` 明確標示所有必填環境變數。

**FR-5.3** 提供 README 說明本地開發啟動步驟（ngrok + LINE Developers 設定）。

## 非功能需求

**NFR-1 部署：** 部署至 GCP Cloud Run，支援 Docker 容器化（沿用 2025 版 Dockerfile 架構）。

**NFR-2 語言：** TypeScript（沿用 2026 版架構）。

**NFR-3 資料庫：** Firestore（GCP 原生，免費額度 1GB 儲存 / 2 萬次寫入/天）。

**NFR-4 LINE SDK：** 使用 `@line/bot-sdk` v8+，注意 Client 類別拆分的 breaking changes。

**NFR-5 PTT 爬取限速：** 每次爬取間隔不低於 1 秒，避免 rate-limit。
